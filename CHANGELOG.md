# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Skills for detailed, spec-style GitHub issues (#23): `iru-draft-github-issue` (interview, functional or
  documentation draft, review loop, create), `iru-review-github-issue` (classified gap/pending/inconsistency/doubt
  findings) and `iru-split-github-issue` (sub-issues ordered by dependency, tracked by a milestone).
- Opt-in blue/green rolling deployments for generated Spring Boot services (#15): `deploy.rolling` manifest block,
  staged `deploy.yml` and a new `promote.yml` workflow, rollout infrastructure for ECS Fargate, Cloud Run and
  EKS/GKE Autopilot, and the `iru-springboot-rolling-deployments` skill to enable or disable it later.
- Plugin marketplace `ai-catalog` (#11): `.claude-plugin/marketplace.json`, generated by `tools/generate-marketplace.py`
  from the membership map `tools/plugins.json`, with `iru-core` (stack-independent skills and the three agents),
  `iru-knowledge` and one plugin per stack (`iru-java`, `iru-springboot`, `iru-quarkus`, `iru-dotnet`, `iru-typescript`,
  `iru-nestjs`, `iru-nextjs`, `iru-react-native`, `iru-php`, `iru-python`, `iru-android`, `iru-swift`, `iru-kmp`,
  `iru-rust`, `iru-go`, `iru-cli`), over the unchanged `.claude/` tree. Copying a skill directory still works.
- `tools/catalog-audit.py` and its budgets in `tools/catalog-budgets.json` (#11): description at most 1,024 characters
  with the invocation form in the first 200, `SKILL.md` size limits, strict-YAML frontmatter, pinned agent models,
  byte-identical shared files, `templates/`/`reference/` path checks and inline cross-model call reporting, plus
  `--plan` to check an implementation plan's shape; before/after snapshots in `tools/baseline/`; unit tests in
  `tools/tests/`; and the `catalog-check.yml` workflow that runs the audit, the marketplace check and the tests.
- `iru-plan` writes an "Acceptance criteria coverage" table and persists unanswerable questions as `[NEEDS CLARIFICATION]`
  markers; `iru-code` refuses to start on an open marker and checks the coverage table before archiving the plan (#11).
- New guides `catalog-architecture` (the former `CLAUDE.md` architecture prose) and `performance-and-token-budget`
  (budgets, model tiers, prompt-cache analysis, plugin-mode agent dispatch, before/after numbers).

### Changed

- Skill and agent descriptions rewritten to fit the budget (about 495,000 characters down to about 75,000, none over
  1,024), with the invocation form first and values quoted in YAML (#11). This also fixes the frontmatter of the 7
  skills that failed to parse and therefore loaded with no description and no model (`iru-knowledge-process-inbox`,
  `iru-setup-android-app`, `-android-gitignore`, `-android-repository`, `-angular-web`, `-swift-gitignore` and
  `-swift-repository`).
- Models are tiered by task type: `haiku` for mechanical gates, version bumps and gitignore scaffolds, `sonnet` for coding
  skills and scaffold/workflow generators (27 `iru-setup-*` skills moved from `haiku`), `opus` only for `iru-explore`,
  `iru-plan` and `iru-pr-review`; the agents now pin a model (`iru-gate-runner` and `iru-change-summarizer` `haiku`,
  `iru-isolated-skill-executor` `inherit`) (#11).
- Generated-file templates moved out of 14 large `SKILL.md` files into `templates/<variant>/<path>` inside each skill
  directory, read only for the variant in use; no `SKILL.md` exceeds 1,000 lines any more (#11).
- Skills that discovered installed language keys with `find .claude/skills` now read the skills available in the session
  first, so key discovery also works when the catalog is installed as plugins (#11).
- Plugin-mode agent dispatch: a bare `subagent_type: "iru-gate-runner"` does not resolve when installed as a plugin, so the
  three agents and `iru-code`, `iru-code-one-task-group`, `iru-issue` and `iru-setup-changelog` state the rule to dispatch
  as `"iru-core:<agent-name>"` in that case (#11).
- `CLAUDE.md` slimmed from 321 to under 100 lines; the architecture prose moved unchanged to the new
  `catalog-architecture` guide (#11).
- Guides `creating-skills-and-agents`, `extending-the-catalog`, `plugins` and `packaging-and-distribution`, and the README,
  document the description budget, the `templates/` convention, model tiers, the audit command and installing the catalog
  as plugins (#11).
