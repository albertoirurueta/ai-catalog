Setup TypeScript Repository

This documentation was generated with the assistance of AI. Please report any inaccuracies.

End-to-end bootstrap for an npm/TypeScript repository of any of five flavors. It collects the flavor, the project’s identity, and the shared pipeline parameters once, then orchestrates six other skills in a fixed order so nothing is asked twice.

Purpose

iru-setup-typescript-repository is the front door for starting (or catching up) a brand-new npm/TypeScript repository, whatever its shape — a published library, a React or Angular web app, or a React Native or Ionic mobile app. Rather than duplicating each flavor’s scaffold logic, documentation setup, .gitignore rules, CI workflows, changelog bootstrapping, or README generation, it resolves the flavor and mode, gathers the project’s identity and the shared pipeline parameters (open-source, publish/distribution, Sonar, integration branch, Node version, package manager) once, and passes each downstream skill only the args keys it actually accepts.

Outputs

  • The flavor’s own scaffold output — package.json and toolchain files (via iru-setup-typescript-library, iru-setup-react-web, iru-setup-angular-web, iru-setup-react-native-app, or iru-setup-ionic-app) — unless mode: existing found one already in place, in which case it is left untouched.

  • A scaffolded Antora documentation site under docs/ (via iru-setup-antora).

  • A root .gitignore covering node_modules/, build output, coverage, and the Antora build output (via iru-setup-typescript-gitignore).

  • build.yml/release.yml/sync.yml/security.yml GitHub Actions workflows and .github/dependabot.yml (via iru-setup-typescript-github-workflows).

  • A root CHANGELOG.md backfilled from git/GitHub release history (via iru-setup-changelog).

  • A root README.md with badges, a project-status table, documentation links, and installation instructions (via iru-setup-readme).

  • A final report summarizing the resolved flavor/mode/identity/license/pipeline parameters, which files were created, updated, or left untouched, the consolidated required-secrets table, decisions made on the user’s behalf, and an explicit warning to review every generated file before building, committing, or relying on CI.

Dependencies

Invokes

Each of the following is invoked via the iru-isolated-skill-executor agent rather than a direct Skill call — every sub-skill re-derives what it needs straight from the filesystem this orchestrator has just written to, so only a short completion summary needs to come back, keeping each sub-skill’s own exploration/file reads out of this orchestrator’s own context:

  • Setup TypeScript Library — Step 5, when flavor: library: writes package.json and the library toolchain, passing identity and pipeline args.

  • Setup React Web — Step 5, when flavor: react: scaffolds a Vite React app, passing identity, pipeline, and storybook args (no publish/distribution key).

  • Setup Angular Web — Step 5, when flavor: angular: scaffolds an Angular CLI app, passing identity (no description), directory, and pipeline args.

  • Setup React Native App — Step 5, when flavor: react-native: scaffolds an Expo-managed app, passing identity (no description), app-slug, app-directory, native-builds, and distribution args.

  • Setup Ionic App — Step 5, when flavor: ionic: scaffolds a Capacitor hybrid app, passing framework, app-id, identity, and distribution args.

  • Setup Antora — Step 6: scaffolds the Antora documentation site, invoked with no args since it derives the component name/title/version directly from package.json. Run before Step 8 so that skill’s own docs-config survey finds it already in place.

  • Setup TypeScript Gitignore — Step 7: writes or updates the root .gitignore, invoked with no args since it explores the repository directly (package manager, framework, Playwright, docs tooling).

  • Setup TypeScript GitHub Workflows — Step 8: writes the CI/CD workflows, passing flavor, the pipeline parameters, publish/distribution/native-builds/framework (only when the flavor uses them), and the derived docs-tool as args.

  • Setup Changelog — Step 9: bootstraps the root CHANGELOG.md, invoked with no args since it works from the repository’s own git tag/GitHub Release history.

  • Setup Readme — Step 10, last: bootstraps the root README.md, invoked with no args since it explores the finished state left by every earlier step.

Invoked by

  • Setup Repository — Step 4, via iru-isolated-skill-executor, when the detected or chosen project type is typescript-library/react-web/angular-web/react-native-app/ionic-app.

Related agents

  • iru-isolated-skill-executor — spawned once per sub-skill (Steps 5–10), so all six sub-skills' own exploration/file-read transcripts don’t accumulate in this orchestrator’s context over the course of a single bootstrap run.
