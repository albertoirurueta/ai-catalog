Setup React Native App

This documentation was generated with the assistance of AI. Please report any inaccuracies.

Scaffold a new Expo-managed (React Native New Architecture only, Cordova-free) app using create-expo-app’s `blank-typescript template, then layer on this catalog’s standard test, lint, build-profile, and Sonar tooling using explicit example templates embedded in the skill and verified together end-to-end.

Purpose

iru-setup-react-native-app bootstraps a managed Expo/React Native app’s scaffold plus a jest-expo
@testing-library/react-native test setup, an eslint-config-expo flat config, Prettier, an eas.json with development/preview/production build profiles, a Maestro smoke-test skeleton, and — when opted in — sonar-project.properties. It produces no committed ios//android/ folders and no Cordova/Capacitor artifacts; for a Capacitor-based hybrid app, Setup Ionic App is used instead.

Purpose group

TypeScript/Node Bootstrap

/iru-setup-react-native-app

Outputs

  • A scaffolded Expo app at app-directory (via create-expo-app@latest --template blank-typescript), or only the missing tooling files when gap-filling an existing scaffold.

  • package.json merged with test/coverage/lint/format/typecheck scripts and this skill’s devDependencies.

  • jest.config.js, a tsconfig.json merge (types: ["jest"]), tests/App.test.tsx, eslint.config.js (generated by npx expo lint), .prettierrc/.prettierignore.

  • eas.json with development/preview/production build profiles (plus a submit.production block when distribution: store).

  • .maestro/smoke.yaml smoke-test skeleton.

  • sonar-project.properties (only when sonar is not none).

  • A report of what was created/left untouched/replaced, unresolved <placeholder> values still needing manual fill-in (e.g. app.json’s bundle identifiers, the Maestro `<app-id>), and required warnings before building, committing, or submitting to a store.

Dependencies

Invokes

None — iru-setup-react-native-app is a leaf skill in the TypeScript/Node bootstrap pipeline; it does not call any other skill in this catalog. Its Step 8 report mentions Check License, Setup TypeScript Gitignore, and Setup TypeScript GitHub Workflows as follow-up work for the user, but never invokes them itself.

Invoked by

  • Setup TypeScript Repository — Step 5, as one of five flavor choices (alongside Setup TypeScript Library, Setup React Web, Setup Angular Web, and Setup Ionic App), via the iru-isolated-skill-executor agent, passing the pre-resolved app-name/app-slug/app-directory/license/developer info/open-source/sonar/native-builds/ distribution/mode via args so this skill’s own questions are skipped. Also runnable standalone.

Related agents

iru-setup-react-native-app itself does not spawn any Agent — it only runs shell commands (create-expo-app, npm, npx expo) and edits files in app-directory.
