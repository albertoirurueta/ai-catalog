= Update Antora
:description: Upgrades an existing Antora docs toolchain to the pinned Antora 3.2.2 set, replaces Lunr with Pagefind and npm ci workflows, and proves it with a build diff.
:keywords: iru-update-antora, claude code skill, antora upgrade, pagefind, lunr, npm ci, package-lock, docs toolchain, nav override, build diff

NOTE: This documentation was generated with the assistance of AI. Please report any inaccuracies.

Upgrade the documentation toolchain of a repository that already builds an Antora site, and prove the upgrade changed
nothing but the toolchain. It never edits page content, `nav.adoc` or `antora.yml` beyond what the upgrade requires.

== Purpose

Antora sites generated by older versions of this catalog pin Antora 3.1, search with the Lunr extension and install the
toolchain in CI with ad hoc commands. `iru-update-antora` moves such a repository to the pinned set kept in its
`reference/toolchain.md` (Antora 3.2.2, Pagefind 1.6.0 replacing Lunr, exact versions and a committed lockfile installed
with `npm ci`), or to a given Antora version (reported as not tested by the catalog). It asks before every change,
builds the site before and after, and reports every difference of the two builds other than the `generator` meta tag
and the sitemap `lastmod`.

== Outputs

* Updated `package.json` and regenerated `package-lock.json` (to be committed) in each Antora toolchain directory.
* When Lunr is replaced: the Pagefind dependency and `search:index` script, the `ui-overrides/` files registered in the
  playbook's `ui.supplemental_files`, and the Pagefind step in the CI workflows.
* Workflows rewritten to `npm ci` in the toolchain directory, `npx antora -v` and the Pagefind step.
* Optionally the slim-nav override and its `scripts/`, and `git rm -r --cached node_modules` when dependencies are tracked.
* Version and install statements in `README.md`, `CLAUDE.md` and Antora pages updated (only those statements).
* A report with the before and after build comparison, the Pagefind result, the nav measure verdict and anything left unverified.
