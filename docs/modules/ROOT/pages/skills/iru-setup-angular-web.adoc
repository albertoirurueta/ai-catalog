= Setup Angular Web
:description: Scaffolds a new Angular application via the Angular CLI, then wires up Vitest coverage, ESLint, Prettier, Stylelint, Playwright, Compodoc, and Sonar.
:keywords: iru-setup-angular-web, claude code skill, angular, vitest, eslint, prettier, stylelint, playwright, compodoc, sonar

NOTE: This documentation was generated with the assistance of AI. Please report any inaccuracies.

Scaffold a new Angular web application with `ng new`, then layer on this catalog's standard toolchain: Vitest
coverage gates, ESLint (angular-eslint), Prettier, Stylelint for SCSS, Playwright e2e, Compodoc API docs, optional
Storybook, and Sonar wiring.

== Purpose

`iru-setup-angular-web` bootstraps an Angular workspace with
`npx -p @angular/cli@latest ng new <name> --standalone --style=scss --routing --skip-git --package-manager=npm
--defaults --ssr=false` (Angular 22's own defaults already give a zoneless, Vitest-backed, standalone-component
workspace) and then fills in everything that scaffold does not include out of the box: confirms `angular.json`'s
`test` target uses `@angular/build:unit-test` with `runner: vitest`, adds `coverageReporters` and an 80%-lines
`coverageThresholds` gate, and installs a matching-major `@vitest/coverage-v8` (the coverage collector `ng new`
does not bundle); `ng add angular-eslint` plus `eslint-config-prettier`; a `.prettierignore` next to the CLI's own
`.prettierrc`; Stylelint 17 for SCSS (`stylelint-config-standard-scss`, with `no-empty-source` disabled to tolerate
the CLI's 0-byte root stylesheet); Playwright via `ng add playwright-ng-schematics` (fixing the schematic's own
hardcoded `/MyApp/` title assertion); Compodoc; optional Storybook; and, when `sonar` is not `none`,
`sonar-project.properties` pointing at the real `coverage/<project>/lcov.info` path. It is the Angular leaf of the
TypeScript/Node bootstrap pipeline, parallel to `iru-setup-react-web`, `iru-setup-react-native-app`, and
`iru-setup-ionic-app`.

== Outputs

* A scaffolded Angular workspace (`angular.json`, `package.json`, `src/`) at the resolved `directory`.
* `angular.json`'s `test` target configured for Vitest with coverage reporters and an 80%-lines threshold, plus
  `@vitest/coverage-v8` installed at the matching `vitest` major.
* ESLint (`eslint.config.js` via `angular-eslint`, extended with `eslint-config-prettier`), a `.prettierignore`,
  Stylelint (`.stylelintrc.json`) for SCSS, and reformatted CLI-generated files (`npx prettier --write .`).
* Playwright e2e (`playwright.config.ts`, `e2e/example.spec.ts` with its title assertion corrected to the real
  project name).
* Compodoc wired via a `docs` npm script producing `docs/api/`.
* Optionally, a Storybook scaffold (`storybook: yes`).
* `sonar-project.properties` at the repository root, only when `sonar` is `cloud` or `self-hosted`.
* A report that opens by repeating the announced mode (from scratch or updating an existing setup), lists per owned artifact the action taken (created / updated / replaced / kept as is / removed) and each mismatch a kept artifact leaves with this run's choices, the `visibility` used for Sonar and where it came from, what ran or was skipped by design, plus explicit warnings to review
  generated files, run Prettier if not already run, and install Playwright browser binaries before `ng e2e`.
