= Setup Android Gitignore
:description: Creates or gap-fills the root and per-module .gitignore files for an Android Gradle project, protecting the vendored JaCoCo CLI jars.
:keywords: iru-setup-android-gitignore, claude code skill, android, gradle, kotlin, jacoco, gitignore, keystore, antora

NOTE: This documentation was generated with the assistance of AI. Please report any inaccuracies.

`iru-setup-android-gitignore` composes the root `.gitignore` and one per-module `.gitignore` for an Android
(Gradle/Kotlin) library or app project, using
https://github.com/albertoirurueta/irurueta-android-glutils[irurueta-android-glutils]'s own `.gitignore`,
`lib/.gitignore` and `app/.gitignore` as the concrete reference templates. It never overwrites an existing
`.gitignore` without first showing the user exactly what would change and getting explicit approval.

== Purpose

The skill produces a house-standard Android `.gitignore`: an unconditional root base (Gradle build output,
`local.properties`, IDE files, keystores, `google-services.json`, JaCoCo profiling output, plus the catalog's own
Antora `docs/build/`/`docs/node_modules/` additions), a one-line anchored `/build` `.gitignore` for each Gradle
module, and conditionally-detected root sections for Detekt/ktlint/Spotless caches and Fastlane output. It
deliberately never ignores the vendored `jacoco-<ver>/` JaCoCo CLI directory that `iru-setup-android-library`/
`iru-setup-android-app` commit into the repository, since CI depends on that directory staying tracked to convert
coverage without a network dependency. It mirrors `iru-setup-java-gitignore`'s diff-and-approve contract, adapted
to the Android/Gradle ecosystem.

== Inputs

|===
|Argument |Required |Description |Default

|`mode`
|No
|`new` or `existing`. Selects whether the skill should expect to write fresh files or gap-fill/merge into files
that already exist.
|Detected from whether a root `.gitignore` already exists (present → `existing`, absent → `new`).

|`modules`
|No
|Comma- or space-separated Gradle module directory names that should each get their own `/build`-only
`.gitignore` (e.g. `lib`, `app`).
|Derived from every `include(":<name>")` entry in `settings.gradle.kts`/`settings.gradle`; if neither file
exists yet, falls back to whichever of `lib`/`app` exist as directories, or asks the user via
`AskUserQuestion`.
|===

== Outputs

* A root `.gitignore` — newly created, or updated after explicit user approval when one already existed.
* A `<module>/.gitignore` for each resolved module (typically `lib`, `app`) — newly created, or updated after
  approval; skipped entirely when its content already matches.
* A closing report stating which root file and each module file was created/updated/left untouched, which
  conditional Step 4 sections (Detekt/ktlint/Spotless, Fastlane) were included versus skipped and why, and
  confirmation that the vendored `jacoco-<ver>/` CLI directory was **not** added to any ignore pattern.
