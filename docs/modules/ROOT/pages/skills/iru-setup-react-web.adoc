Scaffold a React + TypeScript web application with Vite, then layer on this catalog's standard
test/coverage/lint/format/e2e toolchain — Vitest, Testing Library, ESLint or Oxlint, Prettier, Stylelint,
Playwright, an optional Storybook setup, and `sonar-project.properties` when Sonar is enabled.

== Purpose

`iru-setup-react-web` bootstraps a new React web app from `npm create vite@latest <name> -- --template
react-ts`, then wires in the house toolchain this catalog expects every TypeScript project to carry: Vitest
(`jsdom`, v8 coverage with lcov) plus `@testing-library/react` for unit tests, ESLint 10 flat config with
`eslint-plugin-react-hooks` (or the Vite template's own Oxlint, kept by choice), Prettier, Stylelint 17 for
CSS, Playwright for an end-to-end smoke test under `e2e/`, an optional Storybook setup, and — when Sonar is
enabled — `sonar-project.properties`. There is no `publish`/`distribution` question for this skill, since a
web app isn't published to a package registry or an app store. Every step was proven against the actual
current tooling (Vite 8, ESLint 10, Vitest 5, Playwright 1.63, Stylelint 17, Storybook 10) in a throwaway
scaffold, so the gotchas called out along the way are observed behavior, not speculation.

== Outputs

* A Vite + React + TypeScript app scaffolded at the repository root or a subdirectory, including
  `package.json`, `vite.config.ts`, `tsconfig.json` (project references), `src/`, and `public/`.
* `vitest.config.ts`, `src/test/setup.ts`, and `src/App.test.tsx` for unit testing.
* `eslint.config.js` (or Oxlint left in place, per `keep-oxlint`), `.prettierrc`, `.prettierignore`,
  `.stylelintrc.json`.
* `playwright.config.ts` and `e2e/smoke.spec.ts` for end-to-end testing, with the Chromium browser binary
  installed locally.
* `.storybook/` and its scripts, only if `storybook: yes`.
* `sonar-project.properties` at the repository root, only if `sonar` resolved to `cloud` or `self-hosted`.
* `tsconfig.e2e.json` and an updated `tsconfig.json` reference list, so `tsc -b` type-checks `e2e/` too.
* A report of what was generated/skipped, every verification command run (typecheck, lint, format, test,
  coverage, build, e2e) and its result, plus explicit warnings to review generated files, wire `SONAR_TOKEN`
  in CI if Sonar was enabled, and provision Playwright browsers in CI.
