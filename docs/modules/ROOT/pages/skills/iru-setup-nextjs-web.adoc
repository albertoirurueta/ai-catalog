= Setup Next.js Web
:description: Scaffolds a Next.js app with create-next-app flags plus Vitest, ESLint, Prettier, Playwright, TypeDoc, Sonar, static export or Docker, and a tested sample feature.
:keywords: iru-setup-nextjs-web, claude code skill, nextjs, create-next-app, vitest, playwright, typedoc, app router, static export, scaffold

NOTE: This documentation was generated with the assistance of AI. Please report any inaccuracies.

Scaffold a Next.js + TypeScript web application with `create-next-app`, driven entirely by explicit flags so saved
preferences can never leak in, then layer this catalog's standard toolchain on top — Vitest with React Testing
Library and jsdom, ESLint flat config with `eslint-config-next`, Prettier, `next typegen && tsc --noEmit`,
Playwright against the production build, TypeDoc, optional Sonar, and either a GitHub Pages-ready static export or a
container-ready server build — plus a tested sample feature. It also brings an existing Next.js app up to the same
toolchain, announcing the mode and asking per artifact what to do with anything that already exists.

== Purpose

`iru-setup-nextjs-web` gives a repository a Next.js app whose npm script names (`lint`, `format`, `format:check`,
`typecheck`, `test`, `coverage`, `test:e2e`, `build`, `start`, `docs`) are exactly the ones
xref:skills/iru-setup-typescript-github-workflows.adoc[] calls for the `nextjs` flavor and the TypeScript gate skills
detect. The sample feature (a `server-only` data layer, async Server Component pages, a Client Component leaf, a Server
Action with Zod validation and an auth stub, Route Handlers, metadata, `loading`/`error`/`not-found`) is the living
example of the `iru-nextjs-code-one-task` references, adapted to static export or the Pages Router where needed.
Templates are kept in `reference/` next to the skill (`config-templates.md`, `app-router-samples.md`,
`pages-router-samples.md`) and were verified in five router/output combinations. The `cache-components` choice
determines the `16-prev` or `16-cc` coding profile later tasks apply.

== Outputs

* A Next.js app (`src/app` or `src/pages`) scaffolded by `create-next-app` with explicit flags, `version`
  `0.1.0-dev.0`, `"private": true`, and a `next.config.ts` variant for the resolved `output`/`distribution`.
* Vitest + React Testing Library + jsdom configuration (v8 coverage, 80% thresholds, lcov at `coverage/lcov.info`),
  ESLint flat config, Prettier config, and the shared npm scripts listed in Purpose.
* The sample feature with colocated unit tests (scaffold-from-scratch runs only), plus `playwright.config.ts` and
  `e2e/` specs when `e2e: playwright`.
* `typedoc.json` when `docs-tool: typedoc`; `sonar-project.properties` when `sonar` is not `none`; `Dockerfile` and
  `.dockerignore` when `distribution: internal`.
* `.gitignore` additions for Playwright, TypeDoc and the integration-test lock.
* A final report with the mode, per-artifact action (created / updated / replaced / kept as is / removed),
  resolved options and their sources, every verification result, and explicit warnings (auth stub, in-memory store,
  static-export limits, secrets).
