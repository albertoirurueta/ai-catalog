= Review GitHub Issue
:description: Reviews a GitHub issue or local draft against a quality checklist and returns classified findings, each with the exact question to ask the user.

NOTE: This documentation was generated with the assistance of AI. Please report any inaccuracies.

Review one GitHub issue, or a local draft of one, for gaps before anyone builds from it.

== Purpose

`iru-review-github-issue` applies a quality checklist (common items, development items for functional issues or
documentation items for documentation issues, plus size signals) and verifies technical details against the code and
cited links by fetching them. Findings are classified as `gap`, `pending`, `inconsistency` or `doubt`, each with the exact
question for the user, and the verdict is `ready` or `needs-work`. It never guesses an answer, and for an existing issue
it only posts a comment or edits the body after explicit confirmation. It stops on non-GitHub hosts.

== Outputs

* A fixed result block (`Verdict`, `Kind`, `Findings`, `Suggestions`), returned unchanged to a calling skill.
* For an existing issue only, and after explicit confirmation: a comment with the findings or an edited body.
* A short report with the verdict, finding counts per class, and a hint about `/iru-split-github-issue` when size
  signals fired.
