Scaffolds a FastAPI service with uv, or brings an existing FastAPI service up to date, and layers this catalog's Python toolchain and a small, tested application skeleton on top.

== Purpose

`iru-setup-python-fastapi` runs `uv init --bare` and `uv add` with pinned ranges (`fastapi[standard]`, Pydantic 2, pydantic-settings, SQLModel or plain SQLAlchemy 2.0 async, Alembic), then writes:

* The layered `app/` package: `main.py` (app factory, lifespan, exception handlers), `settings.py` (`APP_` prefix, `SecretStr`), `dependencies.py` (`Annotated` aliases), `db.py`, `routers/`, `services/` (with a `Protocol` port), `data/` adapters and `models/`.
* `/healthz` and `/readyz` probes and one sample CRUD resource (router, service, repository) with fast tests on in-memory SQLite and a testcontainers PostgreSQL integration tier marked `@pytest.mark.integration`.
* Alembic with an async `env.py`, a naming convention and a reviewed initial revision; optional PyJWT and pwdlib Argon2 bearer-token auth.
* Every tool config in `pyproject.toml` (Ruff, mypy strict with the Pydantic plugin, pytest markers, coverage with an 80% floor and XML at `build/coverage/coverage.xml`), `scripts/export_openapi.py` and Sphinx API docs sources in `docs/api/`.
* A multi-stage non-root uv `Dockerfile`, `.dockerignore`, `compose.yaml` (`postgres:18`, a one-shot `migrate`, the app), `.env.example` and, when Sonar is enabled, `sonar-project.properties`.

The generated code is the first exemplar of the `iru-fastapi-code-one-task` conventions, and its commands, paths and markers are the scaffold contract that the `iru-python-*` gate skills and `iru-setup-python-github-workflows` rely on. The skill announces whether it is scaffolding from scratch or updating an existing service and, per owned artifact that already exists, asks **Update** / **Keep as is** / **Replace** (or **Stop**) unless `on-existing` pre-answers. Replace is never offered for application source, tests or applied migrations.

Other keys (`ci-tests`, `pages`, `publish`, `flavor`, and so on) are ignored. An existing `pyproject.toml` that is not a FastAPI service (Django, a library, Flask) stops the skill; a non-uv runner offers **Adopt uv** or **Stop**.

== Outputs

* `pyproject.toml`, `uv.lock` and `.python-version` with version `0.1.0.dev0` and all tool sections.
* The `app/` package and `tests/` (`conftest.py`, `fakes.py`, `unit/`, and `integration/` with PostgreSQL).
* With a database: `alembic.ini`, `migrations/` (async `env.py`, `script.py.mako`, `versions/0001_create_book_table.py`).
* With `auth: yes`: `app/security.py`, auth models and router, and the auth versions of settings, dependencies and tests.
* `scripts/export_openapi.py`, `docs/api/conf.py` and `docs/api/index.rst`.
* `Dockerfile`, `.dockerignore`, `compose.yaml`, `.env.example`, and `sonar-project.properties` when Sonar is enabled.
* A report: mode, per-component action (created / updated / replaced / kept as is / removed / skipped), resolved shape, versions and drift past the pins, each verification command and result (unverified items such as Docker-dependent steps called out), and warnings (review identity and Sonar keys, never commit `.env`, run migrations once per release, one Uvicorn process per container).

No `.gitignore`, workflows, `CHANGELOG.md`, `README.md` or Antora files are written; the orchestrator runs the dedicated skills for those next.
