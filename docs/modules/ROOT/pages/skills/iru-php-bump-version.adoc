= PHP Bump Version
:description: Sets a PHP project's version to an exact value in every flavor-specific location for Laravel, WordPress, PrestaShop or Composer libraries.
:keywords: iru-php-bump-version, claude code skill, php, version bump, laravel, wordpress, prestashop, composer, release, dev version

NOTE: This documentation was generated with the assistance of AI. Please report any inaccuracies.

Set a PHP project's version to an exact, caller-supplied value across every file its flavor keeps a version in, following
the catalog's `x.y.z-dev` development-version convention.

== Purpose

`iru-php-bump-version` never computes a version; it validates the given string (`X.Y.Z` or `X.Y.Z-dev`, flagging
anything else) and applies it. An embedded Python helper with `--list` and `--dry-run` modes detects the flavor and
rewrites exactly the known locations: Laravel `config/app.php` `'version'`; WordPress plugin or theme `Version:`
header plus `<PREFIX>_VERSION` constant; PrestaShop `$this->version` plus a tracked `config.xml`. WordPress
`readme.txt` `Stable tag:` is written only for release versions, and a `package.json` version is updated through
`npm version --no-git-tag-version` so its lockfile follows. A plain Composer library has no in-tree version (the git tag
is the version), so nothing changes and that is reported. The helper refuses to write when locations disagree until the
user confirms. Step 5 documents the pre-release convention that `iru-release` calls it against, including the PrestaShop
`VARCHAR(8)` truncation caveat for `-dev` values. It can optionally sync README and Antora version mentions.

== Outputs

* Updated version locations for the detected flavor, and a synchronized `package.json` and lockfile via npm for WordPress.
* Optionally updated README and Antora mentions.
* A report: flavor and detection, each location with its old value, the new version, every file touched (or that a library
  changed nothing), whether `Stable tag:` was written, any PrestaShop upgrade-script note or `-dev` caveat, and the
  `php -l` result.
