= Python Coverage
:description: Measures line and branch coverage of a Python project's fast pytest suite with pytest-cov or coverage.py and reports per-target gaps from Cobertura XML.

NOTE: This documentation was generated with the assistance of AI. Please report any inaccuracies.

Run a Python project's fast (container-free) pytest suite with coverage.py enabled and report the exact, measured line and branch coverage for the files the caller cares about, read from a Cobertura XML report. It is a read-only measuring skill: it never adds tests, modifies source or test code, or changes coverage configuration unless asked to as a follow-up.

== Purpose

A coverage number is only meaningful if coverage is actually wired and the right code is measured. `iru-python-coverage` checks that `pytest-cov` (or at least `coverage`) is installed, reads the project's `[tool.coverage.*]` configuration (`source`, `omit`, `branch`, `fail_under`, `concurrency`), runs the fast selection with coverage, and computes line %, branch % and coverage.py's combined % from the XML. The gate run always deselects integration tests, because a figure that depends on Docker cannot be reproduced without it. A missing wiring, a run that wrote no report, or a target outside the measured source is reported instead of a misleading percentage.

== Outputs

* A plain-text summary in the conversation: the runner, how coverage was collected (pytest-cov or `coverage run`), the measured roots (`source` or the chosen `--cov=` packages), the test selection and what was deselected, and whether the tests passed.
* Total line %, branch % and coverage.py's combined %, with a verdict on whether the line % meets the bar.
* Per target (or per file): line % and branch %, and for every target under the bar the uncovered line ranges and partial branches.
* Under-reported numbers are flagged, for example async SQLAlchemy code invisible without `concurrency = ["greenlet", "thread"]`.
* The Cobertura report `build/coverage/coverage.xml` and the JUnit log are left in place when `build/` is gitignored, otherwise deleted. No source, test or configuration is ever modified.
