Scaffold or update the `build.yml`, `release.yml`, `sync.yml` (library/react/angular flavors only), and
`security.yml` GitHub Actions workflows plus `.github/dependabot.yml` that make up an npm/TypeScript
repository's CI/CD release pipeline, for whichever of five flavors the repository actually is.

== Purpose

`iru-setup-typescript-github-workflows` wires up the house pipeline for an npm/TypeScript repository of one of
five flavors — `library` (a published npm package), `react` (a Vite/React web app), `angular` (an Angular CLI
web app), `react-native` (an Expo app), or `ionic` (an Ionic + Capacitor hybrid app). `build.yml` runs install,
lint, format check, typecheck, unit tests with coverage, an optional SonarQube/SonarCloud scan (skipped on
fork pull requests), Playwright e2e for the web flavors, a docs build (TypeDoc/Compodoc/Storybook) merged with
an Antora build, and a GitHub Pages deploy from the stable branch only. `release.yml` is flavor-specific: npm
publish via OIDC trusted publishing plus an optional Changesets version-PR job for `library`; a web-bundle deploy
to Pages for `react`/`angular` (`dist/` for Vite, `dist/<project>/browser/` for Angular); EAS or local Gradle/Xcode builds for `react-native`; Android/iOS store or
internal artifacts for `ionic`. `sync.yml` (library/react/angular only) plus its companion
`.github/scripts/sync_versions.py` merge the stable branch back into the integration branch and bump
`package.json` to the next `x.y.(z+1)-dev.0` prerelease. `security.yml` runs the shared
Dependabot/dependency-review/CodeQL/OSV-Scanner/gitleaks block. The skill ships generic example templates
embedded in the skill file, resolves versions at run time against the npm registry and GitHub Releases API,
and resolves every other placeholder from a survey of the target repository rather than guessing. If any of
the workflow files already exist, it asks the user whether to stop or attempt an update using the templates as
reference (or goes straight to the update path when `mode: existing` was supplied), preserving any step this
skill doesn't own.

== Outputs

* `.github/workflows/build.yml` and `.github/workflows/release.yml` — created fresh, or updated in place if
  either already existed and the user chose to continue.
* `.github/workflows/sync.yml` and `.github/scripts/sync_versions.py` — written together, only for the
  `library`/`react`/`angular` flavors; never generated for `react-native`/`ionic`.
* `.github/workflows/security.yml` and `.github/dependabot.yml` — always created or updated, independent of
  `flavor`/`sonar`/`publish`/`distribution`.
* Supporting files created if missing: `sonar-project.properties` (when `sonar` isn't `none`), and
  `.gitignore` entries for `dist/`, `coverage/`, `docs/api/`, `docs/build/`, `storybook-static/`.
* A report of required repository secrets (per the flavor/`sonar`/`publish`/`distribution`/`native-builds`
  actually resolved) and repository settings that must be enabled, plus any open gaps (missing Playwright
  config, missing `ExportOptions.plist`, README/Antora wording that didn't match `sync_versions.py`'s default
  regexes, non-patch-level releases the bump default doesn't handle).
