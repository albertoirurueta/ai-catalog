== Purpose

`iru-setup-quarkus-repository` is the Quarkus orchestrator in this catalog's repository-bootstrap family. It supports
Java or Kotlin, Maven or Gradle (Kotlin DSL), and a single-module or hexagonal multi-module layout. It collects the
project identity (groupId, artifactId, base package, description, developer details, license), the shape (language,
build tool, layout, Java version), the pipeline parameters (integration and stable branches), and the visibility-aware
choices: open source, visibility, CI, which tests CI runs, GitHub Pages, whether a container image is published, and
SonarCloud/SonarQube/none. It then chains `iru-setup-quarkus-service`, `iru-setup-antora`, `iru-setup-java-gitignore`,
`iru-setup-quarkus-github-workflows`, `iru-setup-changelog` and `iru-setup-readme`, each through
`iru-isolated-skill-executor`, passing each sub-skill only the `args` keys it accepts so nothing is asked twice.

It announces the setup mode up front (from scratch, or updating an existing repository with an inventory of every owned
component marked absent, present or partial); each sub-skill then asks keep, update or replace for what it finds, and
the final report lists the action taken per component.

== Outputs

* A Quarkus service repository: `quarkus-stack.yml`, build files and wrapper, sources, quality and Sonar configuration,
  Antora docs, `.gitignore`, GitHub workflows with Dependabot and the shared security block (unless `ci: no`),
  `CHANGELOG.md` and `README.md`.
* A final report repeating the setup mode and giving, per component, the action taken (created, updated, replaced,
  kept as is, skipped, or not written), the verification results from the service skill, how each resolved choice was
  wired or omitted, the required-secrets table and repository-settings notes, and explicit review warnings.
