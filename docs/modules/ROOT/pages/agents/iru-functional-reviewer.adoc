= Functional Reviewer

A custom, read-only agent that reviews one functional definition draft for completeness, correctness and verifiability.

== Purpose

`iru-functional-reviewer` reads the checklist and the draft, runs every checklist item, verifies every named artefact in
the repository with `file:line` evidence, fetches cited URLs, and hunts `missing-functionality` and `incorrect`
statements (including verification methods that are infeasible in the repository). It never edits anything and never
changes a ticket, and returns only a `Verdict` / `Findings` / `Suggestions` block. It runs as an agent so the verbose
repository inspection stays out of the caller's context.

Tools: `Read`, `Grep`, `Glob`, `Bash` (read-only commands) and `WebFetch`. Model: `opus`.
